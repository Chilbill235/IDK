Getting started

SafeBeef runs entirely in your browser. No installation is required — just open it, create a local account, and you're in.

How do I create an account?

Open the sign-in page and pick a username. Passwords are optional in the demo environment and stored only in your browser. Nothing is transmitted.

Do I need more than one browser tab?

Some modules (Hook Engine, chat) work best with multiple tabs open — one tab acts as the "attacker," another as the "target." Open the app in two tabs, sign in as different users in each, and the modules will see each other.

Where is my data stored?

Everything is stored in localStorage and sessionStorage in your own browser. Clearing site data will reset your account, messages, and settings.

Is anything sent to a server?

No. SafeBeef has no backend. Multi-tab features work through BroadcastChannel, which is local-only. See the Privacy Policy for details.

Keyboard shortcuts

Ctrl + K — Command palette

Opens a searchable command palette. Jump to any module, user, or setting without touching the mouse.

/ — Focus module search

Pressing / on the main workspace focuses the module search box.

Esc — Close current panel

Closes the active chat, mod panel, settings, or command palette. Also dismisses the topmost toast notification.

↑ / ↓ — Console history

In the console pane, use arrow keys to cycle through your command history.

Modules

What is a "module"?

Each module demonstrates one security concept — for example, "XSS Demo" shows how untrusted input can run script in another user's tab. Click any module card to run it.

Do modules actually attack anything?

No. Every module is simulated. They may display realistic-looking output (fake cookies, fake console logs), but no real network requests are made and no external system is touched.

What does "Live Data" mean on some modules?

Modules tagged LIVE pull real data from public demo APIs (e.g., inspirational quotes, Pokémon info) to make their output feel authentic. These are read-only GET requests to well-known public APIs — no personal data is sent.

Why are some modules greyed out?

Some modules require a "hooked" target. Hook a user first from the left pane, then run the module.

Chat & messaging

How do I start a chat?

Click 💬 in the top bar, pick a user, and type. Conversations are local — they only exist between tabs signed in on your device.

Why can't I send messages?

If you're muted, frozen, or banned, the input is disabled and a banner explains the reason and remaining time. Contact a moderator or submit an appeal from the ban screen.

Can I send files?

Yes — images, video, audio, and "Digital Touch" are supported through the attach menu (＋ button). Files are encoded as data URLs and stay local.

How do I report a user?

Right-click any conversation in the Messages sidebar and choose Report user…. You can also right-click any incoming message and choose Report message… to include it in the report.

Moderation

How do I become a moderator?

Only the owner can promote users. If you're the owner, open the moderation panel → Role Management. Otherwise, ask the owner.

What can moderators do?

Moderators can warn, mute (temporary or permanent), freeze (read-only access), kick (force sign-out), and ban users. They can also review appeals and see an audit log.

What's the difference between a mute, freeze, and ban?
  • Mute — user can read but not send messages
  • Freeze — user is locked out of all actions until unfrozen
  • Ban — user is signed out and shown the ban screen; they cannot log in until unbanned or the ban expires
What happens when I get 3 warnings?

Three warnings within 24 hours trigger an automatic ban. Warnings clear from the counter after 24 hours of clean behavior.

Account & bans

I've been banned. What now?

You'll see the ban screen with the reason, issuer, and remaining time. If appeals are enabled, submit one — a moderator will review it. Bans expire automatically when their timer runs out.

How do I appeal a ban?

On the ban screen, click Appeal, type a short explanation, and submit. You can only have one pending appeal at a time.

Can I have multiple accounts?

Technically yes (they're local), but abuse of multiple accounts to evade bans is against the Terms.

How do I delete my account?

SafeBeef doesn't have a delete button — because there's no server. Simply clear your browser's site data for this origin. All accounts, messages, and settings will be gone.

Troubleshooting

Modules aren't loading / blank page

Try a hard refresh (Ctrl+Shift+R or Cmd+Shift+R). If that fails, clear site data and sign in again.

Chat isn't updating between tabs

Make sure both tabs are on the same origin (same protocol + host + port) and both signed in. BroadcastChannel only works between same-origin tabs.

Toasts are missing or truncated

Check that toast.js and toast.css (or the toast rules in styles.css) are loaded. The toast system falls back to console.info if the module is missing.

I lost my role / account vanished

Roles and accounts are stored in localStorage. If you cleared site data or opened a private window, they're gone. The owner account can usually be recreated by signing up with the same username on a fresh session.

Colors look wrong / theme is stuck

Theme is stored in sb26_settings. Open Settings (⚙) → Appearance → Theme to reset. If the page can't load styles at all, ensure styles.css is served correctly.

Still stuck?
SafeBeef is an educational demo, not a production service. There is no official support channel. If something is broken, clear your site data and start fresh — that resolves 90% of issues.
